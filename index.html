Where Everything Lives, Syncs & How It Is Protected

1
Why Localhost & GitHub Web Both Work (Two Doors, One Vault): localhost:8000 (your MacBook Air local server) and omgorigold-maker.github.io/finland-web (your Universal Cloud Web App) both read and write to the exact same private finland-vault ledger.
2
Mac mini ↔ MacBook Air Two-Way Sync (How Info Changes Are Handled): Any edit you make on your Mac mini saves straight to your Private GitHub Vault (finland-vault) in 1–2 seconds using UTC timestamps. Your MacBook Air checks finland-vault every 30 seconds (and right before every Wise card check), pulls any Mac mini edits automatically, and mirrors them to iCloud Drive/Finland-Backup.
3
Wise Card API Privacy & Zero-Duplicate Lock: Nobody on the internet can see your Wise pulls — your Wise token lives only on your private Mac, and Wise transactions are saved only inside your private finland-vault. Only your MacBook Air polls Wise (the old isolated Mac mini local server is automatically disabled), and every card charge is locked by its unique Wise transaction ID so duplicates can never happen.
4
Full-Screen Security Gate & Browser Memory (Lock This Browser): The public code contains zero personal notes, bills, documents, or keys. Once you unlock a browser with your Pairing Link or Cloud Key, Chrome remembers it in website storage (localStorage) even if you delete files in Finder. Click Lock This Browser below anytime to wipe browser memory and return to the solid lock screen.
5
Triple Automatic Backups, Clean finland_* Schema & Anti-Wipe Guard: All storage keys use the clean finland_* naming standard. Every save is scrutinized so an empty or unrefreshed tab can never wipe your data, and is backed up to ~/.finland/, Private GitHub (finland-vault), and 90-day rolling snapshots in iCloud Drive/Finland-Backup/snapshots/.
